# Mobility category checks

Install development dependencies with `npm install`, then install a browser with `npx playwright install chromium`.
Run `npm run test:mobility`.

To use an existing Chromium installation, set `CHROMIUM_EXECUTABLE` to its executable path.
Optional `MOBILITY_SCREENSHOTS` names an existing folder for temporary visual checks.

The test uses a local HTTP server and blocks external requests. It checks the home picker without the GitHub discovery service, all 16 animated demos and camera buttons, paused frames, independent saved settings, mobile width, and live-session pause/stop controls.

The routines contain general exercise information and configurable starting examples. They do not provide an individual rehabilitation prescription. Source links are available within each routine.
